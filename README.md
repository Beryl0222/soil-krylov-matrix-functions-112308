# 冻土脉冲积热的矩阵函数作用与子步准入

冻结时窗内的冻土层热参数与地表信号。 仓库记录均为本地合成资料，不依赖外部数据服务。

## 数据约定

cap 是各层正热容量，g 是相邻层传导，每格内热源为 body。top 和 bottom 为 [h,a,b]，从外侧进入柱体的热通量为 a + b * (t − 窗起点) − h * 边缘层温度。单层柱两端共同作用。

热容乘温度变化率等于邻层流入、边界流入及体热源之和。积分热量方向沿用入柱为正的定义。输出可复核列总热量变化是否与已积边界及体源相等。

同一批配置中给两种乘算调用预算，统计有效稀疏作用以及用于证明误差的追加作用。1.25 是下一冻结窗口的开始，时间恰为事件可读取旧窗口终值，跨事件后需要新系数。

## 读取与核对

在 Python 3.11 环境执行 `python -m pip install -r requirements.txt` 安装数值依赖。
`python -m unittest discover -s tests -v` 读取 `data/exchange.json` 并核对资料结构与关键输入关系。
